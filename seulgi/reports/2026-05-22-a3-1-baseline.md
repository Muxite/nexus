## 4. Root-cause hypotheses

In priority order:

1. **Size divergence (PRIMARY, blocks comparison)**: live system was running on per-engine `max_position_usdc=$1.0` for super_scout and similar micro-stake floors, producing $1-5 trades historically. Current config.yaml has most balanced/inverted engines at `max_position_usdc=100.0` (lines 590, 719, 804). The backtest faithfully sizes off the current config and produces $27-48 trades. **This isn't a bug — it's the cost of using `--variant-config config.yaml` against historical decisions taken under a different sizing regime.** Phase 1 A1.1 did NOT change sizing — these knobs were already this way; what changed is that `disable_below_usdc 5.0 → 0.50` now lets slippage actually bite on stakes ≥ $0.50, where before the historical $1-5 stakes all walked 0.
2. **Slippage curve (CONFIRMED, secondary)**: A1.1 lowered `disable_below_usdc` from 5.0 → 0.50. At a $33 stake the linear 2 bps/$ walk adds ~0.66% to entry price (matches the +0.0068 we measured). Live $1.59 stakes historically saw 0 walk → 100% of live trades had 0 slippage. So even if we held sizing constant, slippage would push backtest > historical loss by ~0.3% of size.
3. **TP/TRAIL gates now net-MTM (FIX-2A)**: cannot test in this window because no backtest trade fires TP/SL/TRAIL within 5 minutes. Need a longer horizon or more volatile markets to surface this.
4. **Fee schedule per market_type (FIX-1)**: not exercised — no exit fees are charged on HOLD MTM in the sim.
5. **EV / compute_ev_yes (A1.2)**: not on the critical path — entry uses `_evaluate_pure` which still reads `min_edge`, not EV.
6. **Confidence semantic disambiguation (A1.2)**: backtest treats `engine_results.confidence` as `p_alpha` (documented in line 372 of `backtest.py`). Cannot test the historical alternative interpretation; will need decision_inputs to disambiguate properly.

The **DATA ROOT CAUSE** that prevents any Phase 3 verdict is that `market_price_snaps` only covers the last ~1.5 days and `trades.realized_pnl` only covers the first ~3 days — the two windows barely overlap.

## 5. Verdict

**❌ Phase 3 exit criterion (±10% per engine) is NOT verified.**

Not because we found > 10% divergences and fingered a Phase-1 fix, but because the **data does not yet support the comparison**:
- Pre-2026-05-21 decisions have NO snap-tape → backtest can't simulate exits.
- Post-2026-05-21 decisions mostly haven't closed live → no historical realized_pnl to compare against.
- The one decision pair that exists for `scout/all_signals` mismatches 100% (live executed, backtest skipped on `size_too_small` because the variant has `max_position_usdc=0.05` and the sim's `min_trade_usdc` floor is $1.0 — see `simulate_min_trade_usdc` on config.yaml line 553).
