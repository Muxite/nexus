## Phase 5 smoke finding — the headline result

50 min of live LLM, full pipeline:
- 687 signals → 215,980 engine_results → **0 trades**.
- Breakdown:
  - 184,187 pre-AI rule skips (85%) — `mid_below_065` + `extreme_low_price` kill 99% of NO-direction signals.
  - 27,196 NEUTRAL (12.6% — A4E.4's prompt rework brought this down from 99.97%).
  - 111 `edge_too_small` (the true-EV gate firing correctly — signal lacks edge).
  - 5,222 `llm_calls` captured (A2.1 writer working).
- 0 crashes, 0 commit-race errors, 0 telemetry drops, telemetry queue drained.

**Conclusion**: the infrastructure is provably correct. **The Stage-3
LLM does not produce calibrated probabilities with enough edge to beat
round-trip fees AT CURRENT GATES.** Two paths forward, complementary:

1. **Loosen gates** (in particular retire `mid_below_065` whose
   evidence base is a 190-row cycle-9 backtest — A0.10). Lets more
   signals reach the AI; might restore volume but probably not PnL.
2. **Improve signal source** — better matching (cross-encoder /
   learned MLP / **irene's knowledge graph**), better LLM prompt
   (A4E.4 helped but more headroom), broader market universe
   (Kalshi/Predictit via `discovery.py`).

Path 2 is where this session and the irene session both want to go.

- **`decision_inputs` writer NOT yet wired into `engine.process`.** The
  table + writer exist (FIX-3); A2.5's integration test xfails until
  the engine.process call is added. This means the backtest's PRIMARY
  oracle is empty; it falls back to `engine_results.classify_result`.
  Should ship in Phase 6 or next session.
- **Pre-AI rules are too aggressive**: `mid_below_065` kills 85% of
  decisions before AI runs. A0.10 audit says evidence is stale
  (cycle-9, 190-row backtest). Recommend reviewing before next live
  cycle.
- **Composite scorer AUC is strong (~0.75) but trader's
  `composite_score_floor` defaults to 0.0** — operator hasn't opted
  in. To enable, set `trading.composite_score_floor: 0.5` (or similar)
  in config.yaml. WARNING: changes execution dynamics significantly.
- **Cross-encoder matcher is scaffolded but not loaded** — needs
  `sentence-transformers` cross-encoder model (50MB download) on
  first call. Default `enabled: false`.
- **Calibration shows YES IC near zero, NO IC=+0.30 (strong)** — the
  model is much more reliably wrong on YES than NO. Worth
  investigating with irene's perspective on YES-side signal.
- **Phase-5 F1 pass criterion (≥50 trades / 4h)**: NOT met — we
  stopped at T+50min with 0 trades. Phase 5 F2 (24h regression) was
  never run. The infrastructure passes; the signal does not yet.
